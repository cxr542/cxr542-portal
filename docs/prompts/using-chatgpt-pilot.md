# ChatGPT 개인 테스트 플러그인 사용 — 2026-10-29

[프롬프트 저장소 테스트](https://chatgpt.com/plugins/plugin_asdk_app_6ae2996e36ac8191b9e5ae6113d2bb00)는 실제 OAuth 연결 및 자연어 등록·검색·수정·즐겨찾기 필터·삭제 검증을 마쳤습니다. 개인 테스트 Preview이며 기존 포털 Production 반영은 별도 단계입니다.

ChatGPT에서 새 대화를 열고 @로 ‘프롬프트 저장소 테스트’를 선택하거나 플러그인 화면의 ‘채팅에서 사용해 보기’를 누릅니다.

- ‘OOTD 프롬프트 찾아줘.’
- ‘이 프롬프트 저장해줘. 제목은 …, 본문은 …, 카테고리는 …, 태그는 ….’
- ‘방금 저장한 프롬프트의 본문을 …로 수정해줘.’
- ‘즐겨찾기한 이미지 생성 프롬프트 보여줘.’
- ‘방금 만든 테스트 프롬프트만 삭제해줘.’

대상 항목이 불명확하면 먼저 검색하고 정확한 제목/ID를 확인합니다. 변경·삭제 요청에는 ChatGPT의 확인이 표시될 수 있습니다. 충돌 시 최신 내용을 확인하고, 삭제한 항목을 자동으로 새로 등록하지 않습니다.

같은 테스트 계정으로 [웹 저장소](https://cxr542-prompt-actions-test.vercel.app/prompt-collection/index.html)에 로그인하면 같은 데이터를 확인할 수 있습니다. 다른 클라이언트 변경은 새로고침으로 반영합니다. 기존 브라우저 데이터 가져오기는 백업·미리보기·명시적 승인 후에만 실행합니다.

OAuth 연결은 연결을 시작한 같은 탭에서 완료합니다. 요청이 만료되면 기존 플러그인에서 연결을 다시 시작합니다. 테스트 계정은 .cache/prompt-cloud/accounts.json의 비공개 로컬 파일에 있고 비밀번호·Client Secret은 채팅에 붙여넣지 않습니다. 기존 실패 플러그인은 교체 과정에서 삭제됐으므로 위의 현재 링크를 사용합니다.
